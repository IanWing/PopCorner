# PopCorner

A lightweight Windows utility that brings customizable hot corners to your desktop.

PopCorner lets you assign actions to any of the four corners of your screen. Trigger predefined actions, keyboard shortcuts, or custom CMD commands simply by moving your mouse into a corner.

## About

PopCorner was created to bring the convenience of hot corners to Windows, just like you would expect them on a Mac or Linux (GNOME) system.

Each of the four corners of your screen can be configured independently, allowing you to quickly trigger actions without reaching for a keyboard shortcut or navigating through menus.

PopCorner is designed to be simple, lightweight, and unobtrusive. It runs quietly in the background and stays out of your way until you need it.


## Features

- **Four configurable corners**  
  Configure each corner independently and assign a different action to each one.

- **Predefined actions**  
  Choose from a selection of actions provided by PopCorner.

- **Custom keyboard shortcuts**  
  Trigger any keyboard combination supported by Windows.

- **Custom CMD commands**  
  Execute your own Windows commands with optional parameters.

- **Lightweight**  
  Designed to use minimal system resources while running in the background.

- **No account required**  
  Just install PopCorner and start configuring your corners.

## Usage

After launching PopCorner, configure the actions you want to associate with each corner.

Each corner can be configured independently:

- Top-left
- Top-right
- Bottom-left
- Bottom-right

Move your mouse into a configured corner to trigger its assigned action.

PopCorner can remain running in the background while you use your computer normally.

## Configuration

PopCorner supports three types of actions:

### Predefined actions

Select one of the actions provided by PopCorner.

### Keyboard shortcuts

Assign a custom keyboard combination to a corner. When the corner is triggered, PopCorner simulates the configured key combination.

### CMD commands

You can configure a custom Windows command and optional parameters to be executed when a corner is triggered.

> **Warning:** Custom commands are executed locally with the same permissions as PopCorner. Only configure commands that you trust and understand.

## System Requirements

- Windows 10 or later
- x64 Windows installation

PopCorner does not require administrator privileges for normal operation.

## Privacy & Security

PopCorner is designed to operate entirely locally on your computer.

- No account is required.
- PopCorner does not collect telemetry.
- PopCorner does not require an internet connection.
- PopCorner does not download executable content.
- PopCorner does not send your configuration or commands to external servers.
- Custom commands are **configured and executed locally by the user**.

PopCorner does not provide remote command execution and does not receive commands from external sources.
